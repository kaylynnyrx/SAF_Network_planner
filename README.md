# SAF_Network_planner
Optimal SAF supply chain for Kalimantan (Airbus Challenge #3). A MILP solver (PuLP/CBC) chooses 6 large refineries and 23 depots with exact on-land coordinates, supplying all four airports with 300 kt SAF each (1,200 kt/yr) at $896M/yr (~$747/t SAF). Logistics emit ~144 kt CO2e/yr (2.8 g/MJ, ~3% of fossil jet's 89 g/MJ baseline; GLEC factors).
